# Real Estate AI

Create a minimal, elegant, and responsive real estate AI landing page.

DESIGN

Premium minimalist aesthetic.

Black, white, and subtle gray color palette.

Elegant typography, clean spacing, and simple layouts.

No unnecessary illustrations, complex animations, or decorative elements.

Lightweight implementation with smooth horizontal transitions.

LAYOUT
Create a single-page application with three centered navigation tabs:

Prompts

Google Login

AI Data

Each tab represents a separate full-screen content section.

INTERACTION

Clicking a tab navigates horizontally to its corresponding section.

Use a simple, smooth horizontal sliding transition.

Highlight the active tab.

Keep navigation and transitions responsive on mobile and desktop.

Avoid unnecessary dependencies.

CONTENT
Each section must contain only its title and an otherwise empty content area.

TECHNICAL CONSTRAINTS

Implement only the initial UI and navigation.

Do not implement authentication, AI integrations, APIs, databases, forms, or persistent storage.

Do not add features beyond the requirements.

Use reusable components and maintainable code.

Do not rebuild or introduce unnecessary project configuration if an existing project is already present.

ACCEPTANCE CRITERIA

All three tabs work correctly.

Horizontal navigation is smooth.

The active tab is visually identifiable.

The layout works on desktop and mobile.

No console errors are introduced by the implementation.

Keep the implementation intentionally simple. Do not implement future functionality.
